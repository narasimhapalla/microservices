# Spring Boot + Microservices Learning Journey

## Project Purpose

This project is created to learn and practice **Spring Boot and Microservices architecture** step by step.

The goal is to build a complete microservices-based Order Management system while understanding how different microservices concepts work together.

---

# Project Architecture

```text
                              CLIENT
                                |
                                |
                                v
                         API GATEWAY
                            Port 8080
                                |
                                |
                                v
                       SERVICE DISCOVERY
                            EUREKA
                            Port 8761
                                |
                --------------------------------
                |              |               |
                v              v               v
         CUSTOMER SERVICE   ORDER SERVICE   PRODUCT SERVICE
                |              |               |
                v              v               v
          CUSTOMER DB       ORDER DB       PRODUCT DB
```

# Services and Ports

| Service                    | Port | Purpose                            |
| -------------------------- | ---: | ---------------------------------- |
| Service Discovery (Eureka) | 8761 | Service registration and discovery |
| API Gateway                | 8080 | Single entry point for clients     |
| Customer Service           | 8081 | Customer management                |
| Order Service              | 8082 | Order management                   |
| Product Service            | 8083 | Product management                 |

> Port numbers can be changed based on project configuration.
